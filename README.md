# BEB Party

同室の5〜6人で遊ぶ英語推理パーティゲーム（人狼型）のWebアプリ。

TOEIC 200点台から900点台までが混在しても全員が同時に楽しめることを目標にする。
プレイヤーは自分のスマホで自分だけの証言カードを受け取り、英語で質問し合って犯人を探す。

## 特徴

* **レベル差を吸収する**: 同じ事実を持つ証言カードが、レベル1〜5の5段階の英文で用意される。初級者は単語だけ、上級者は曖昧な複文で同じ情報を持つ
* **全員が必要になる**: 犯人の嘘は、他の2人以上の証言を突き合わせたときにだけ矛盾が現れる。寡黙な人が1人いると真相に届かない構造を、事件データの機械検証で保証する
* **アプリは英語を理解しない**: 会話は対面の生声、勝敗は投票で決まる。音声処理もAI採点も使わないため、運用費が¥0で成立する
* **必要なのはスマホだけ**: テレビやPCがなくても遊べる。ブラウザで部屋コードを入れるだけで参加できる

## 技術構成

| 層 | 技術 |
| --- | --- |
| フロントエンド | Vite + Svelte + TypeScript（スマホ縦持ち専用のSPA） |
| 配信 | Cloudflare Workers（静的アセット） |
| リアルタイム同期 | Cloudflare Durable Objects（部屋 = 1インスタンス、WebSocket Hibernation API） |
| データストア | なし（部屋の状態はDO内で揮発。DBを持たない） |
| 事件データ | リポジトリ内の静的JSON + 前方推論によるCI検証 |
| CI/CD | GitHub Actions → `wrangler deploy` |

すべてCloudflareの無料枠で動作させる。有料サービスとランタイムのAI APIは導入しない。

## 開発

前提: Node.js LTS、pnpm、Cloudflareアカウント（無料プラン）。

```bash
pnpm install
pnpm dev              # client(Vite) + server(wrangler dev) を同時起動
pnpm test             # ユニットテスト
pnpm validate:cases   # 事件データの整合性検証
pnpm check            # lint + 型チェック
```

コマンドの実体はM0で確定させる。
コードを書く前に [CLAUDE.md](CLAUDE.md) の不変条件と、触るモジュールの基本設計を読むこと。
