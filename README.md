# BEB Party

同室の5〜6人で遊ぶ英語パーティゲーム集のWebアプリ。

TOEIC 200点台から900点台までが混在しても全員が同時に楽しめることを目標にする。
1つの部屋基盤の上に複数のゲームを載せ、その日の気分と人数で選んで遊ぶ。

最初の収録は英語推理ゲーム **ENGLISH DETECTIVES**（人狼型）。
プレイヤーは自分のスマホで自分だけの証言カードを受け取り、英語で質問し合って犯人を探す。

## 特徴

* **レベル差を吸収する**: 同じ事実を持つ証言カードが、レベル1〜5の5段階の英文で用意される。初級者は単語だけ、上級者は曖昧な複文で同じ情報を持つ
* **全員が必要になる**: 犯人の嘘は、他の2人以上の証言を突き合わせたときにだけ矛盾が現れる。寡黙な人が1人いると真相に届かない構造を、事件データの機械検証で保証する
* **アプリは英語を理解しない**: 会話は対面の生声、勝敗は投票で決まる。音声処理もAI採点も使わないため、運用費が¥0で成立する
* **必要なのはスマホだけ**: テレビやPCがなくても遊べる。ブラウザで部屋コードを入れるだけで参加できる
* **ゲームを足せる構造**: 部屋・参加者・レベル・秘密情報配布・進行管理はゲーム非依存の共通コアにあり、ゲームは1本ずつモジュールとして追加できる

## 収録ゲーム

| ゲーム | 内容 | 状態 |
| --- | --- | --- |
| ENGLISH DETECTIVES | 質問と推理。証言を突き合わせて犯人を当てる | 実装済み（実プレイ未実施） |
| DON'T SAY IT | 禁止語を避けて英単語を説明する | 候補 |
| ENGLISH ESCAPE | 協力型。各自の情報を統合して脱出する | 候補 |
| LOST IN TRANSLATION | 伝言ゲーム。各自に異なる伝達制約が付く | 候補 |
| BROKEN STORY | 順に英文物語を継ぎ足す | 候補 |

候補の実装順と収録可否は未確定（[docs/構想v2.md](docs/構想v2.md)）。

## 現在の状況

**M2（DETECTIVES本体）実装済み・実プレイ未実施**。

M0（骨組み）とM1（検証エンジンと事件1本）は完了した。
M1では汎用推論エンジン（`shared/engine`）と事件データの検証7項目を実装し、事件を1本収録した（[docs/事件レビュー/cafe-theft.md](docs/事件レビュー/cafe-theft.md)）。

M2ではDETECTIVESの4ステージ（ブリーフィング・捜査・投票・開示）をサーバとクライアントの両方に実装した。
6人での部屋作成から開示までの通しE2EがCIで通る。

事件は7本収録している（各6バリアント）。ロビーで指定するか、「おまかせ」を選べば開始時にサーバが抽選する。
各事件は3巡のクロスレビュー（構造と検証 / 犯人の手札の自己整合 / 英語の質とゲーム体験）を経ており、記録は [docs/事件レビュー/](docs/事件レビュー/) にある。

残るM2の完了条件は実プレイである。実際の6人プレイで1事件を完走し、市民勝率を記録する（[docs/実装計画/M2.md](docs/実装計画/M2.md)）。
デプロイにはCloudflareのAPIトークンをリポジトリシークレットへ設定する必要がある（[docs/開発ガイド.md](docs/開発ガイド.md) の実プレイ前のリリース手順）。

卓の共有画面（`/room/:code?mode=host`）は、ステージ名・残り時間・参加者だけを大きく出す読み取り専用モードとして実装済みである（[docs/基本設計/02_クライアント.md](docs/基本設計/02_クライアント.md)）。
未解消の課題は [docs/既知の課題.md](docs/既知の課題.md) にまとめている。

マイルストーンは [docs/設計.md](docs/設計.md) の開発ロードマップを参照。

## 技術構成

| 層 | 技術 |
| --- | --- |
| フロントエンド | Vite + Svelte + TypeScript（スマホ縦持ち専用のSPA） |
| 配信 | Cloudflare Workers（静的アセット） |
| リアルタイム同期 | Cloudflare Durable Objects（部屋 = 1インスタンス、WebSocket Hibernation API） |
| データストア | なし（部屋の状態はDO内で揮発。DBを持たない） |
| コンテンツ | リポジトリ内の静的JSON + CI検証（DETECTIVESは前方推論による整合性検証） |
| CI/CD | GitHub Actions → `wrangler deploy` |

コードは「ゲームを知らない共通コア（`core/`）」と「ゲーム1本ごとのモジュール（`games/<id>/`）」の2層に分かれる。
境界の定義は [docs/基本設計/05_ゲームモジュール.md](docs/基本設計/05_ゲームモジュール.md)。

すべてCloudflareの無料枠で動作させる。有料サービスとランタイムのAI APIは導入しない。

## 開発

前提: Node.js LTS、pnpm、Cloudflareアカウント（無料プラン）。

```bash
pnpm install
pnpm dev              # client(Vite) + server(wrangler dev) を同時起動
pnpm test             # ユニットテスト
pnpm validate:content # コンテンツの整合性検証
pnpm check            # lint + 型チェック
```

コマンドの定義は [docs/基本設計/07_リポジトリとツールチェーン.md](docs/基本設計/07_リポジトリとツールチェーン.md)。
コードを書く前に [CLAUDE.md](CLAUDE.md) の不変条件と、触るモジュールの基本設計を読むこと。
