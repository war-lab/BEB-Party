## ロビーがDETECTIVES固有の語彙を持っている（2026-08-18、2本目の追加で顕在化）

`client/core/src/components/Lobby.svelte` に、ゲーム固有の概念が3箇所ある。
共通コアはゲームを知らないという不変条件4（[ADR-0009](./adr/0009-部屋基盤とゲームモジュールの分離.md)）に反する。

| 箇所 | 内容 |
| --- | --- |
| 見出し | 「事件を選ぶ」。DON'T SAY ITではお題セットを選ぶ場面であり、文言が誤っている |
| 設定の入力 | 「捜査時間（秒）」の数値入力（300〜1200）が、どのゲームを選んでも出る |
| `configure` の送信 | 常に `settings: { investigationSeconds }` を送る。ゲーム固有の設定名が共通コアに埋まっている |

DON'T SAY IT側では実害が2つある。
`roundSeconds` をロビーから変更できず既定90秒に固定される。
選んでも効かない「捜査時間」の入力が出る。

`validateSettings` は知らないキーを無視するため、進行そのものは壊れない（実測）。

直し方は `client/app` が `gameId → 設定UI` のテーブルを渡す形（`gameScreens` と同じ構造）が素直である。
ただし共通コアの変更を伴うため、着手前に [基本設計/05](./基本設計/05_ゲームモジュール.md) の境界定義の議論へ戻す（同文書の手順6）。

確度: **実測**（DON'T SAY ITのロビーで「事件を選ぶ」と「捜査時間（秒）」が表示されることを確認）。
