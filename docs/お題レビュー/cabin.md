## 結論

`content/escapecall/cabin.json`（規則5種の言い回し15文、質問と確認の言い回し11件、舞台の文言）の収録時の記録である。

水準は**作成時のAI（Claude Opus 5.5）による自己点検1回だけ**である。
複数観点のクロスレビューと、実際の参加者による確認は行っていない。

機械検証（検証10項目）はPASSした。
機械検証が担保するのは形式だけであり、英文の意味が規則の作用と一致するかは担保しない（[基本設計/13](../基本設計/13_ESCAPECALLゲームモジュール.md)の「機械で検査しないもの」）。

規則の言い回し15文は、[lab.md](./lab.md) の4観点クロスレビューで確定した文を1字も変えずに使った。
舞台に合わせた言い換えは、規則の作用とずれる経路を新たに作るおそれがあるため行わなかった。

舞台の文言と錠の名前は新しく書いた。
質問と確認の言い回しは、lab.json と同じ11件の型を保ち、例に出す記号と数字だけを変えた。

錠の名前は、錠1から順に工具箱、物置の扉、無線室の扉とした。

## クロスレビュー

複数観点のクロスレビューは**実施していない**。

作成時の自己点検は、実施主体がAI（Claude Opus 5.5）1体であり、次の項目を見た。

| 対象 | 確認した内容 | 結果 |
| --- | --- | --- |
| 規則の言い回し | 舞台に合わせて言い換えるか、lab.json の文をそのまま使うか | そのまま使った（下に理由を記す） |
| 質問と確認の例 | 例の記号が `symbols.ts` にある色と形の組か | 赤い四角、青い星。どちらも16種に含まれる |
| 確認の例の数字 | 錠1と錠2の答えの桁数（4桁）と一致し、数字に重複が無いか | 6, 1, 3, 9。4桁で重複は無い |
| `Blue or black?` | 例を変えるか | 変えなかった。lab.md が聞き違えやすい組として追加した確認であり、舞台に依存しない |
| 導入文の締め | before night comes と before it gets dark のどちらにするか | before it gets dark とした。口語でよく使う形であり、日本語も「暗くなる前に」と対応する |
| 錠の名前 | 画面での表示 | 解錠中とふりかえりの両方で日本語を併記する（`Solving.svelte`、`Debrief.svelte`） |

規則の言い回しを lab.json と同じにした理由は次のとおりである。

規則の作用は舞台に依存しない。
記号を除く、並びを逆に読む、答えの両端を入れ替える、数字に1を足す、の5つであり、山小屋でも研究所でも同じである。

lab.md の巡では、`swap_ends` と `add_one` で答えを取り違える経路が2件見つかり、範囲（of the answer）と対象（For nine）を足して直した。
舞台の語（例えば「無線の周波数」「工具の番号」）を文に入れると、何の最初と最後か、何に1を足すかの範囲がまた曖昧になるおそれがある。
舞台の雰囲気は導入文と錠の名前で出せるため、規則の文で出す利点は小さい。

## 未解決の論点

* lab.md の「未解決の論点」と「残した論点」は、規則の文が同じであるためこのパックにもそのまま当てはまる
* `storeroom` `radio room` がレベル1〜2に通じるかは確かめていない。錠の名前は日本語を併記するため、理解の妨げにはならないと見込むが、声に出して言えるかは別である
* 作戦会議の画面は `titleEn` だけを見出しに出し、`titleJa` を出さない（`Briefing.svelte`）。`Snowed-In` はレベル1〜2に通じない可能性がある。ロビーの日本語の題名と導入文の日本語で補えると見込むが、確かめていない
* 導入文が英語3文で、lab.json（3文）と同じ文数だが1文が長い。作戦会議の90秒で読めるかは確かめていない
* 日本語の文言に新しい漢字（雪、暖炉、無線など）がある。フォントサブセットは統合時に `fonts:generate` で作り直す必要があり、このブランチでは作り直していない

## レビューの限界

* 確認はAI1体の自己点検だけであり、lab.md の4観点クロスレビューより水準が低い
* 規則の文の妥当性は lab.md の結論に依拠しており、このパックで改めて検討していない。lab.md の限界（同じモデルの4体で見落としを共有している可能性など）もそのまま引き継ぐ
* 導入文と錠の名前の英語が自然かは、AIの判断であり、英語話者の確認ではない
* 語彙の難度はAIの推定であり、学習者での確認ではない
* E2E（`pnpm e2e`）はこのパックでは実行していない。E2Eは「深夜の研究所」を題名で選んで通すため、このパックを通す経路は無い
