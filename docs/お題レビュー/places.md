## セットの骨格

| 項目 | 内容 |
| --- | --- |
| カード | 100枚（検証4の下限30枚に対して70枚の余裕） |
| 制約カード | 6枚（`verbs_only` / `three_words` / `question_form` / `past_tense` / `no_size` / `no_activity`） |
| 重要表現 | 9件（うち4件は全セット共通の進行用） |
| 名所・世界の都市 | 57枚 |
| 身近な場所 | 43枚 |
| 日本国内 | 14枚（`Mount Fuji` / `Tokyo Tower` / `Kyoto` / `Hokkaido` / `Okinawa` / `Nara` / `Osaka` / `Shibuya` / `Akihabara` / `Sapporo` / `Fukuoka` / `Kamakura` / `Nikko` / `Ginza`） |

名所と身近な場所を1セットに混ぜている。

名所だけにすると知識ゲームに寄り、Famous Figures と同じ「知らなければ沈黙する」経路が強く出る。
身近な場所だけにすると Everyday Things との差が小さくなる。
混ぜることで、山札から易しい札と難しい札の両方が出る形にした。難度の分布は制御していない（カードに難度を持たせない方針。[基本設計/09](../基本設計/09_DONTSAYITゲームモジュール.md)）。

### 制約カードから `no_country` を外した理由

人物セットの `no_country`（国名と地名を使わない）を、このセットには載せていない。

制約カードは難度が高いこと自体は前提だが、このセットでは「難しい」ではなく「不成立」に近づく。
`Eiffel Tower` / `Taj Mahal` / `Niagara Falls` のような名所は、国名も地名も使わずに一意に指すのが極めて難しい。
100枚のうち57枚が名所・世界の都市であり、レベル5の説明者がこの制約を引いた回はラウンドの半分以上が実質的に説明不能になる。
都市（`Berlin` / `Cairo` / `Seoul` 等）を足したことでこの比率は上がっており、`no_country` を戻す余地はさらに狭まった。

代わりに、このセットで説明の中心になる2つの軸を塞ぐ制約を置いた。

| 制約 | 塞ぐもの |
| --- | --- |
| `no_size` | 大きさと高さ。「とても高い」で名所を絞る経路 |
| `no_activity` | そこで何をするか。用途で施設を当てさせる経路 |

`past_tense`（過去形だけで説明する）は人物セットから引き継いだ。
場所の説明は現在形に寄りやすく、過去形への縛りが実際に負荷になる。

## 自己点検（クロスレビューの代替）

作成時に次を確認した。**独立した観点による検証ではない**。

* **知名度**: 名所・世界の都市57枚は、日本の学校教育と一般的な旅行番組の範囲で選んだ。`Colosseum` / `Sahara` は英語名が出るかに不安があると判断したが、日本語回答を許す規則があるため残した
* **禁止語の並び順**: 先頭3語に「所在」「見た目の特徴」「連想される語」が来るよう並べた
* **説明の成立性**: 5語すべてを禁止した状態で、各カードに1本ずつ説明の道筋があることを机上で確認した

| 論点 | 内容 |
| --- | --- |
| クロスレビュー未実施 | 最大の論点である。独立した観点で見れば、Famous Figures と同程度の指摘が出ると見込む |
| 名所と身近な場所の難度差 | 山札は主題を見ずにシャッフルするため、`Taj Mahal` と `zoo` が同じ確率で出る。レベル1の説明者が名所を引く回が事故になる可能性がある。確度: **未検証** |
| 回答の粒度 | `hot spring` に「温泉」、`convenience store` に「コンビニ」と答えるのは一意に指しているため正解とする。一方「お風呂」「店」は種類だけの回答であり正解にしない。この線引きが卓ごとにぶれる可能性がある |
| 日本国内14枚の英語名 | `Nara` / `Hokkaido` は英語で説明するときに地名以外の手がかりが薄い。`no_size` を引くとさらに狭くなる |
| `Osaka` と Famous Figures の衝突 | Famous Figures の `Naomi Osaka` は、説明者が出身地の文脈で `Osaka` と言うと違反になる（[既知の課題](../既知の課題.md)）。逆にこのセットでは `Osaka` が正解であり、同じ語が別のセットで別の役割を持つ。実害は見込んでいないが、続けて2セット遊ぶ卓では混乱しうる |
| `rooftop` / `basement` の抽象度 | 固有の場所ではなく建物の一部である。「場所」の範囲として自然かは判断が割れうる |
| 都市名の説明の型 | 追加した都市11枚（`Seoul` / `Singapore` / `Bangkok` / `Hong Kong` / `Dubai` / `Moscow` / `Berlin` / `Barcelona` / `Amsterdam` / `Cairo` / `Rio de Janeiro`）は、国名を言えばほぼ終わる。禁止語の先頭が国名であるため、レベル3以上には効くが、レベル1〜2は先頭3語を失った状態で国名以外の手がかりを出す必要がある。負荷が逆転している可能性がある。確度: **未検証** |
| 日本国内14枚の卓依存 | `Shibuya` / `Akihabara` / `Ginza` は関東圏の参加者に強く偏る。`Kamakura` / `Nikko` も同様である。地方在住の参加者が想起できるかは見ていない |
| 施設の一般名詞の粒度 | `school` / `bank` / `hotel` のような一般名詞は、説明が始まった瞬間に当たることが多い。上級者には易しすぎる可能性がある。一方でレベル1〜2の成功体験の札としては機能する |
| `Louvre` の綴りと発音 | 正解が英語話者以外に発音しにくい。日本語回答（「ルーブル」）を許す規則があるため成立はするが、説明者が正解を口に出しにくい点は残る |

## レビューの限界

* **クロスレビューを経ていない**。この記録は作成者自身の点検であり、独立した検証ではない
* **実プレイのデータがない**。所要時間・得点分布・成立枚数はいずれも未実測である
* **知名度の判断に根拠がない**。「日本の学校教育の範囲」は作成者の推定であり、教科書や調査と突き合わせていない
* **`no_country` を外した判断が実測に基づかない**。「57枚が実質的に説明不能になる」は机上の見積りである。実際に試して成立するなら、制約を戻す余地がある
