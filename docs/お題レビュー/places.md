## セットの骨格

| 項目 | 内容 |
| --- | --- |
| カード | 100枚（検証4の下限30枚に対して70枚の余裕） |
| 制約カード | 6枚（`verbs_only` / `three_words` / `question_form` / `past_tense` / `no_size` / `no_nearby`） |
| 重要表現 | 9件（うち4件は全セット共通の進行用） |
| 名所・世界の都市 | 57枚 |
| 身近な場所 | 43枚 |
| 日本国内 | 14枚（`Mount Fuji` / `Tokyo Tower` / `Kyoto` / `Hokkaido` / `Okinawa` / `Nara` / `Osaka` / `Shibuya` / `Akihabara` / `Sapporo` / `Fukuoka` / `Kamakura` / `Nikko` / `Ginza`） |

名所と身近な場所を1セットに混ぜている。

名所だけにすると知識ゲームに寄り、Famous Figures と同じ「知らなければ沈黙する」経路が強く出る。
身近な場所だけにすると Everyday Things との差が小さくなる。
混ぜることで、山札から易しい札と難しい札の両方が出る形にした。難度の分布は制御していない（カードに難度を持たせない方針。[基本設計/09](../基本設計/09_DONTSAYITゲームモジュール.md)）。

### 制約カードから `no_country` を外した理由

人物セットの `no_country`（国名と地名を使わない）を、このセットには載せていない。

制約カードは難度が高いこと自体は前提だが、このセットでは「難しい」ではなく「不成立」に近づく。
`Eiffel Tower` / `Taj Mahal` のような名所は、国名も地名も使わずに一意に指すのが難しい。
100枚のうち57枚が名所・世界の都市であり、この制約は**地理知識への依存と負荷の偏りが大きい**ため今回は外す。

初版のこの節は「57枚が実質的に説明不能になる」と書いていた。
PRレビューの指摘により訂正した。裏付けがない断定であり、実際には成立する名所がある。
観点Cは `Niagara Falls`（`water`/`Canada`/`loud` を封じても `border`/`boat` に経路が残る）を成立例として挙げており、「不能」ではなく「難度と負荷の偏り」が正しい理由である。

代わりに、このセットで説明の中心になる2つの軸を塞ぐ制約を置いた。

| 制約 | 塞ぐもの |
| --- | --- |
| `no_size` | 大きさと高さ。「とても高い」で名所を絞る経路 |
| `no_nearby` | 近くにあるもの。位置関係で名所を絞る経路 |

初版は `no_nearby` ではなく `no_activity`（そこで何をするかを言わない）だった。
観点Bが**重要表現と正面衝突している**ことを指摘し、差し替えた。

> 重要表現の先頭2件「It is a place where ...」「You go there to ...」は、どちらも「そこで何をするか」を述べる型である。レベル5でこの制約が出た卓では、画面が「この型を使え」と「この型は禁止」を同時に表示する。

加えて観点Bは、汎用の場所56枚が禁止語側に既に行為動詞（`swim` / `buy` / `wait` / `ride` / `eat` / `learn` / `pray`）を持つため追加難度が小さいことも指摘した。
`no_nearby` は禁止語がほとんど塞いでいない軸（位置関係）を塞ぐため、レベル5への上乗せとして機能する。

重要表現も同じ指摘で入れ替えた。名所44枚の主経路である**位置**と**建造の歴史**の型が1件もなかったため、`It is between ... and ...` と `It was built long ago.` を追加した（後者は `past_tense` とも噛み合う）。

`past_tense`（過去形だけで説明する）は人物セットから引き継いだ。
場所の説明は現在形に寄りやすく、過去形への縛りが実際に負荷になる。

### 10語の選び直し

末尾を機械的に切って確定させていない。次の基準で選んだ。

1. 既存の禁止語と禁止範囲が重複しない
2. 実際に説明に使いそうな語である
3. 禁止しても、別の説明経路が残る

複合語と単語のどちらを残すかは、**決め手になる語句を残し、汎用語は開けた**。
`Oprah Winfrey` は `talk show` を残して `show` を落とし、`Bruno Mars` は曲名 `Uptown Funk` を残して `funk` を落とした。

初版の記述は「説明経路をより広く塞ぐ側を残した」としていたが、PRレビューの指摘により訂正した。
単語のほうが禁止の範囲は広い（`show` を禁じればあらゆる用法が塞がる）。
残したのは範囲の広い側ではなく、**その語句が出たら正解が割れる決め手の側**である。
汎用語を開けておくと説明の余地が残るという副次的な利点もある。

## 10語のクロスレビュー2巡（2026-09-09）

2026-09-08に禁止語を10語へ増やしたが、そのときのクロスレビューは**5語時代のデータに対して行ったもの**だった。
10語の一覧そのものは作成者の自己判断しか根拠になっていなかったため、改めて3観点を回した。

観点の担当は固定したまま、問いを1巡目と変えた（[README](./README.md) の「レビューの観点を固定する」）。

| 観点 | この巡の問い |
| --- | --- |
| A | レベル別の提示数 3/3/5/7/10 は成立するか。実効難度はどうなっているか |
| B | 10語にしても1語で即答される経路が残っていないか。禁止語は英語として自然か |
| C | 「機微な語は先頭3語へ」の規則が10語への書き換え後も守られているか |

### この巡でいちばん重い結果

3観点が独立に**約250件**を挙げた。機械検証は当時0エラー・0警告だった。

最大のクラスは「同じ概念に2枠を使っている」（4セット合計55枚）で、
これは検証13を新設して潰したはずの欠陥と**同じ性質が別の軸から出たもの**である。
前の巡を「11枠を直した」で終わらせたことが原因であり、
正しい閉じ方は「そのクラスを検査に落とす」だった。

この巡では検証14〜17を追加し、それが挙げた枠をすべて差し替えた
（[基本設計/09](../基本設計/09_DONTSAYITゲームモジュール.md) の検証項目）。

| 検査 | 内容 | 4セット合計 |
| --- | --- | --- |
| 検証14 | 語形変化だけが違う枠（`small` と `smallest`、`Spain` と `Spanish`） | 11枠 |
| 検証15 | 別名を構成する語が禁止語の枠にある（別名 `chemist` と枠 `chemist shop`） | 5枠 |
| 検証16 | 英式の語の混在。綴りの変種（`grey`/`gray`）と別の語になる対（`queue`/`line`） | 23枠 |
| 検証17（警告） | 同じ概念に2枠（`soccer` と `football`） | 66枠 |

機械に落とせなかった指摘は次のとおりで、レビューでしか見つからない。

* 禁止語が英語として自然か（語順が逆の `hair long`、非文の断片 `science too`）
* その語が説明者の口から実際に出るか（`clink` `nearest` `many names`）
* 機微な語の判断

### 作成者の側の誤りとして記録すること

検証17の根拠を初版で**逆に書いていた**。
「片方を禁止すればもう片方を言う理由がない（＝枠が死ぬ）」と書いたが、これは誤りである。
`hot` を塞げば説明者は `warm` へ逃げるため、両方を塞ぐこと自体には効果がある。

正しい根拠は別で、レベル1〜2には先頭3語しか提示しないため、
3枠のうち2枠が同じ概念だと**そのレベルで塞げる経路が2つに減る**ことである。
枠の死ではなく概念の被覆の狭さの問題であり、差し替えという対処は変わらないが理由が違う。

同種の取り違え（説明経路をより広く塞ぐ側を残した／決め手になる語句を残した）を
2026-09-08にも指摘されており、この成果物で2度目である。

**現存する汎用の場所が約60枚**あり、全文過去形で説明すると「今はない場所」と読めると指摘した。
`famous-figures` で「存命の人物を過去形で説明すると引退・故人と読める」として記録された問題と同型で、
このセットでは該当が6割に及ぶ。**制約の入れ替えは行っていない**。

`Broadway` と `subway` の `way`、`Big Ben` の `big`、`Times Square` の `time` が
正解の構成語として封じられる点は**未対処**である。カードの維持と削除の判断を保留している。

`Okinawa` の `American base`（8位）は観点Cが挙げたが、**そのまま残した**。

地理的な事実として中立に読める範囲と判断した。この判断は覆りうる。

## レビューの限界

* **クロスレビューを経ていない**。この記録は作成者自身の点検であり、独立した検証ではない
* **実プレイのデータがない**。所要時間・得点分布・成立枚数はいずれも未実測である
* **知名度の判断に根拠がない**。「日本の学校教育の範囲」は作成者の推定であり、教科書や調査と突き合わせていない
* **`no_country` を外した判断が実測に基づかない**。「地理知識への依存と負荷の偏りが大きい」は机上の判断である。実際に試して成立するなら、制約を戻す余地がある
