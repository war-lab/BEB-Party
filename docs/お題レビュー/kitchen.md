# お題レビュー: BLIND ROOM「台所」

## 結論

`content/blindroom/kitchen.json`（アイテム20件と言い回し18件）の収録前レビューの記録である。

水準は**AI（Claude Opus 5.5）による作成時の自己点検1巡**である。
複数観点のクロスレビューと、実際の参加者による確認は行っていない。

機械検証（検証13項目）と、アイコンの検査7項目はPASSした。
機械で検査しない項目のうち、絵と英語名の一致と44pxでの取り違えは、生成したSVGを画像にして目視で確かめた。
この目視もAIが行ったものであり、人の目では確かめていない。

未解決の論点は、`standard` の色ペアが見本に出ないラウンドと、`pan` の語の範囲である（「未解決の論点」）。

## セットの骨格

| 項目 | 内容 |
| --- | --- |
| アイテム（easy） | 10件、1語、すべて違う形。pot / pan / bowl / bottle / kettle / spoon / fork / apple / egg / fridge |
| アイテム（standard） | 10件、2語。5つの形（pot / pan / bowl / bottle / kettle）× 赤と青 |

テーマは「部屋のもの」と重ならないように、台所の調理器具と食べ物に揃えた。
`room` の `cup` は台所にもあるが、形状と語の重複を避けるため入れていない。

`standard` は `room` と同じく「5つの形 × 2色」とした。
色はすべて無生物（鍋、フライパン、お椀、びん、やかん）に付けた。

## クロスレビュー

実施していない。
本記録の確認は、作成したAI自身による自己点検である。

### 絵の確認の方法

生成したSVGを、Playwright（Chromium）で1枚のコンタクトシートに並べて撮影し、その画像を見て確かめた。

* マスの地は盤面と同じ `#f7f8fd`、枠は盤面と同じ半透明の2px線にした
* 各セットの10点を、見本と同じ1マス85pxと、開示と同じ1マス44pxの2段で並べた
* アイコンはマスの85%の大きさで描いた（`BoardGrid.svelte` と同じ）

シートの作成スクリプトは作業用であり、リポジトリには置いていない。

### 確認した項目と結果

| 項目 | 結果 |
| --- | --- |
| 絵が英語名どおりに見えるか | 初版の `pan` は真上から見た円と柄であり、44pxで虫めがねに見えた。`kettle` は上の取っ手が本体に隠れて見えなかった。描き直した後は10点とも名前どおりに見えると判断した |
| easy の10点を44pxで取り違えないか | 取り違えの候補は見当たらなかった。`pot` と `kettle` は、ふたと両側の取っ手か、注ぎ口と上の取っ手かで分かれる |
| standard の赤青を44pxで見分けられるか | 5組とも見分けられた。`pan` は着色した面が横に細いが、焼き面も着色したため44pxでも色が読める |
| standard の5つの形を44pxで取り違えないか | `pan` と `bowl` はどちらも横に広い浅い形であるが、`pan` には長い柄があり、`bowl` には台がある。取り違えないと判断した |

白で塗った `bowl` と `fridge`、白身が白の `egg` は、マスの地（`#f7f8fd`）と同じ色になる。
輪郭線で形が読めるため採った。`room` の白い `cup` と `clock` と同じ扱いである。

### 言い回しの点検

`describerHints` の先頭2件は `room` と同じ枠にした。
どの盤面の広さでも使える組であり、テーマに依存しない。

| # | 枠 | 役割 |
| --- | --- | --- |
| 1 | `Put the ... in the ... row, on the ... side.` | 絶対位置（左右の列） |
| 2 | `Put the ... in the ... row, ... from the left.` | 絶対位置（数える） |
| 3 | `The ... is under the ...` | 相対位置 |
| 4 | `Yes, it is under the ...` | 質問への応答 |

レベル1〜2へ届く4件は「絶対位置2件、相対1件、応答1件」であり、`room` と同じ配分である。
3件目と4件目を `under` にしたのは、`keyExpressions` の `Is it under the ...?` と往復を揃えるためである。

`keyExpressions` には `room` の `Is it next to the ...?` に代えて `Is it under the ...?` を入れ、`Is it second from the left?` を足した。
後者は `describerHints` の2件目と同じ言い方で問い返せるようにするためである。

後者は空欄を使わず、序数を書いた完成文にした。
画面の注記は「`...` はものの名前に置き換えてください」と案内しており、序数を入れる空欄を置くと注記と食い違うためである。

## 確定した変更

| 対象 | 変更前 | 変更後 | 理由 |
| --- | --- | --- | --- |
| `pan` の形状 | 真上から見た円と柄 | 斜め上から見た浅い側面と焼き面、長い柄 | 44pxで虫めがねに見えた |
| `pan` の焼き面 | 暗色で塗る | 本体と同じ色で塗る | standard で着色した面が細く、赤青が読みにくかった |
| `kettle` の取っ手 | 低い弧 | 高い弧 | 本体に隠れて見えなかった |
| `keyExpressions` の5件目 | `Is it ... from the left?` | `Is it second from the left?` | 空欄に序数を入れる枠は、空欄をものの名前とする画面の注記と合わない |

## 未解決の論点

| 論点 | 内容 |
| --- | --- |
| standardの色ペアが出ないラウンド | 見本5個に同じ形の赤青が1組も入らない確率は12.7%（252通り中32通り）である。`room` と同じ構造であり、同じ確率になる |
| `pan` の語の範囲 | 英語の `pan` は片手鍋も指し、`pot` との境界が話者によって揺れる。絵はフライパンであり `ja` も「フライパン」とした。`frying pan` にすると語が明確になるが、standard で `red frying pan` の3語になる |
| `bowl` の `ja` | 絵は台のある椀であり「お椀」とした。調理用の「ボウル」を思い浮かべる参加者がいる可能性がある |
| 序数を入れ替えて使えるか | `Is it second from the left?` は序数を書いた例文である。聞き手が `third` 等へ入れ替えて使うことを前提にしており、その前提は**未検証**である |
| 届かない枠 | easy の5〜7件目と standard の3〜5件目は、どのレベルにも配られない。`room` と同じ構造である |

## レビューの限界

* 実際の参加者による確認をしていない。「英語で説明したくなるか」「75秒で置けるか」は実プレイでしか分からない
* 絵の確認は、AIがPC上のChromiumで撮った画像を見て行った。スマートフォンの実機、人の目、実際の視距離では見ていない
* 複数観点のクロスレビューをしていない。作成者と確認者が同じAIであり、作成時の思い込みを確認で見落としている可能性がある
* 既存作品との造形の一致は、幾何形状の自作であることを根拠に「該当なし」と判断した。図案を1件ずつ第三者と突き合わせてはいない
* フォントのサブセット（`fonts:generate`）は再生成していない。新しい `ja`（鍋、椀、冷蔵庫 等）の字形がサブセットに含まれるかは**未検証**である
