# お題レビュー: Great Figures（great_figures_v1）

## 結論

173枚・制約カード6枚・重要表現9件を収録した。検証17項目とリントをすべて通過している。

初版は200枚だった。3観点のクロスレビュー1巡で**27枚を削除**し、7枚の禁止語を差し替えた。
削除の内訳は、知名度で25枚（観点Aと観点Cが独立に「卓の過半が名前を言えない」と判定したもの）と、安全性で2枚（説明の安全な経路が存在しないもの）である。

**クロスレビューは1巡である**。[Famous Figures](./famous-figures.md) の最初の36枚は2巡（独立評価＋衝突裁定）を経ているが、このセットは1巡目の報告を裁定者1人が処理した。

**10語の一覧については3観点のクロスレビュー2巡を経ている**（2026-09-09）。
1巡目は5語時代のデータに対するものであり、10語の一覧そのものは作成者の自己判断しか根拠がなかったため回し直した。
2巡目は約250件を挙げ、うち機械で判定できるクラスは検証14〜17として実装した。

**実プレイは経ていない**。知名度・所要時間・得点分布はいずれも未実測である。

このセットは Famous Figures から知識寄りの層を分離するために作った。
[Famous Figures](./famous-figures.md) がキャラクターと現代の有名人に寄る一方、こちらは学校で習う偉人・科学者・作家・芸術家で構成する。
どちらを使うかはホストが卓に合わせて選ぶ。

お題データの正本は `content/dontsayit/great-figures.json`、ルールの正本は [基本設計/09](../基本設計/09_DONTSAYITゲームモジュール.md) である。

### Famous Figures と重複させていない

Famous Figures に既に入っている偉人17名（`Albert Einstein` / `Isaac Newton` / `Marie Curie` / `Charles Darwin` / `Thomas Edison` / `Leonardo da Vinci` / `Vincent van Gogh` / `Pablo Picasso` / `Mozart` / `Beethoven` / `Cleopatra` / `Napoleon Bonaparte` / `Mother Teresa` / `Nelson Mandela` / `Martin Luther King` / `Oda Nobunaga` / `Sakamoto Ryoma`）は、このセットに入れていない。

### 制約カードを Famous Figures と同じにした理由

`no_country`（国名と地名を使わない）と `no_job`（職業と役割の名前を使わない）を、人物セットと同じ構成で載せている。

偉人の説明は「どこの国の人か」と「何をした人か」に強く寄る。
この2つを塞ぐと難度が上がるが、業績・逸話・外見・時代で説明する道が残るため成立する。
`places` セットで `no_country` を外したのとは事情が違う（あちらは正解そのものが地名であり、代替の道がない）。

## 日本人名の表記規約

このセットで規約を決めた。Famous Figures にも遡って適用している。

| 対象 | 表記 | 例 |
| --- | --- | --- |
| 明治維新（1868）より前に活動した人物 | 日本語語順 | `Oda Nobunaga` / `Tokugawa Ieyasu` / `Murasaki Shikibu` / `Katsushika Hokusai` |
| 明治以降の人物 | 英語圏で定着した表記 | `Yukichi Fukuzawa` / `Hideyo Noguchi` / `Soichiro Honda` / `Natsume Soseki` |

判断基準を「語順の統一」ではなく「英語圏で実際に使われている表記」に置いた。
語順で機械的に統一すると、`Shohei Ohtani`（Famous Figures）を `Ohtani Shohei` に、`Naomi Osaka` を `Osaka Naomi` にする必要があり、いずれも英語圏で使われない形になる。
説明者が声に出す名前であり、回答者が英語で答えうる名前でもあるため、実在の表記から外れる不利益が語順の一貫性より大きいと判断した。

明治以降の人物でも `Natsume Soseki` が日本語語順なのは、それが英語圏の定着表記だからである（筆名は語順を入れ替えない扱いが一般的である）。
同じ表の `Yukichi Fukuzawa` は西洋式であり、同時代の2名で語順が違う。
規約が「語順」ではなく「定着表記」を基準にしているためであり、規約内では矛盾しない。ただし**表を見ただけでは一貫していないように見える**。

なお正解の判定は「一意に指していれば正解」であり（[基本設計/09](../基本設計/09_DONTSAYITゲームモジュール.md)の判定の規則）、姓名の語順違いは正解になる。
表記規約が卓の裁定に影響することはない。影響するのは説明者が画面で見る文字列だけである。

## 自己点検（クロスレビューの代替）

作成時に次を確認した。**独立した観点による検証ではない**。

* **知名度**: 日本の中学・高校の教科書と、お札・教科書の図版に出る範囲を上限として選んだ。上限を超えると判断して外した候補がある（`Rumpelstiltskin` / `Zeami` / `Katsu Kaishu`）
* **禁止語の並び順**: 先頭3語に「代表的な業績」「国または時代」「よく知られた逸話」が来るよう並べた。レベル1〜2はこの3語を失う

* **宗教上の人物**: `Buddha` と `Confucius` は収録し、イエスとムハンマドは収録していない。卓で「当てる対象」にすることへの抵抗が参加者によって大きく違いうるため、機械検証の外の判断として外した

対象はこのセット200枚（当時）を含む4セット573枚のうち、クロスレビュー未実施だった537枚である。

### 両観点が「このままマージすべきでない」と判定した

4セット中、このセットだけが不可の判定を受けた。根拠は独立していた。

* 観点A: 200枚のうち約63枚（31.5%）が「卓の過半が名前を口に出せない」帯にあると見積り、超幾何分布で**リスク札が1ラウンドに2枚以上入る確率を50.4%**と算出した。スキップは1ラウンド1回であり、半分のラウンドでスキップが足りない
* 観点C: 別の見積り（機能しないカードの確率 p=0.30）から、**ラウンドの約47%が持ち時間の途中で機能停止する**と算出した

2体の枚数の見積り（29枚／約30枚）と結論が独立に一致したため、削減を採用した。
**どちらの数値も実測ではない**（確度: 未検証）。

### 裁定1: 日本語名の追加で解消した指摘は削除しない

観点Aの指摘のうち最も件数が多かったのは「**説明者が英語名を読んでも誰か分からない**」という型である。

> 日本の教科書表記は「エカチェリーナ2世」「ピョートル大帝」。英語綴り `Catherine` / `Peter` からロシアの君主へ結びつく参加者は少数。説明者側の認識失敗であり、回答を日本語で許す規則では救えない。

観点Aはこの型で `Johannes Vermeer`（フェルメール）/ `Charlemagne`（カール大帝）/ `Catherine the Great` / `Peter the Great` / `Joan of Arc`（ジャンヌ・ダルク）/ `Qin Shi Huang`（秦の始皇帝）/ `Kublai Khan`（フビライ）/ `Sun Yat-sen`（孫文）/ `Laozi` の削除を推奨した。

**この型は削除しない。** 同じレビューで観点Aが指摘した別の問題（日用品の英語名が読めない）への対処として、説明者と監視役に日本語名を配る仕組みを本PRで新設したためである。
`Johannes Vermeer` のカードには「フェルメール」が並んで出る。指摘された認識失敗の経路は消える。

観点Aはこの変更を知らずにレビューしている（作業中の変更だった）。指摘が誤っていたのではなく、**前提が変わった**。

削除したのは「日本語名を出しても卓の過半がその人物を知らない」と見込むもの、すなわち観点Aと観点Cが独立に挙げたものに限る。
`Grace Hopper` に「グレース・ホッパー」を添えても知名度は上がらない。

### 裁定3: 安全性で削除した2枚

観点Cは「気まずい可能性がある」ではなく「卓の会話が止まる経路が一本道で存在する」ものを挙げた。

**`Robert Oppenheimer`**（禁止語 `bomb, desert, physics, project, regret`）。
レベル1〜2は `bomb`/`desert`/`physics` を失い、残るのは `project`/`regret` である。
日本人卓で残る説明経路は事実上「日本に落とされた兵器を作った人」の一本になる。
禁止語 `regret` の存在は作成側がこの経路を認識していたことを示すが、**禁止語は語を封じても話題を封じない**（言い換えは許すため）。

**`Yukio Mishima`**（禁止語 `Japan, novels, muscles, death, dramatic`）。
レベル1〜2に開くのは `death` と `dramatic` である。
残る経路は「劇的な死に方をした作家」であり、自死を得点材料にすること、日本の政治に触れること、職場同席の卓であることが同時に重なる。

どちらも並び替えでは解決しない。禁止語を増やしても、封じるほど残余経路がその話題に寄る構造だからである。

観点Cは `Anne Frank` と `Malala Yousafzai` の削除も推奨した。**この2枚は残した。判断が割れたまま記録する。**

### 裁定5: 観点Cの提案を採らなかったもの

観点Cは `Sigmund Freud` の禁止語に `sex` を、`Sandro Botticelli` に `naked` を追加して経路を封じることを提案した。

`Botticelli` は削除したため論点が消えた。
`Freud` については**提案を採らなかった**。理由は観点C自身が立てた軸1と衝突するためである。

> 禁止語は説明者と監視役の画面に表示され、`debrief` では全員の画面に開示されるため、機微な語を禁止語に置くと「その話題が本命の説明経路である」という指示として卓に届く。

`sex` を禁止語に置くと、その語が3つの画面に出る。封じる利益より、卓に話題を指示する害が大きいと判断した。
代わりに並び替えで対処した（`dreams, couch, Austria, mind, cigar` → `couch, dreams, Austria, cigar, mind`）。
`mind` を5位に置くことで、レベル1〜4に「心を研究した人」という無害な経路を開けている。

レベル5では5語すべてが封じられ、残余経路の問題は残る。**未解決の論点として記録する。**

## 禁止語を10語へ増やした（2026-09-08）

収録数を5語から10語へ増やし、レベル別の提示数を 3/3/5/7/10 とした（[基本設計/09](../基本設計/09_DONTSAYITゲームモジュール.md)のレベル差の吸収）。
**提示数は実プレイで確かめるための暫定値である。**

クロスレビュー観点Bの結論が根拠である。

> 説明が成立しないカードは573枚中0枚。問題は一貫して**逆方向**、すなわち5枠で塞ぎきれず1語で即答されるカードの多さである。

5枠しかないと、有用な禁止語を捨てて別の禁止語を入れる取引が生じていた。
前巡の修正では、共演者名を入れるために既存の禁止語を落とす取引を46回行っている。

### 初版の15語から10語へ下げた

最初は15語で実装したが、PRレビューで3点の指摘を受けて10語へ下げた。

| 指摘 | 内容 | 対処 |
| --- | --- | --- |
| 冗長な枠 | 追加した語句に先行する禁止語がそのまま含まれていた。**573枚中116枚・134枠**（`ruler` の `straight` / `line` に対する `straight line`、`Pikachu` の `cheek` に対する `red cheek`）。読む負担だけ増えて難度は上がらず、実効的な制限数がカードごとに変わる | 検証13を新設し、134枠すべてを差し替えた |
| 監視役の負荷 | 監視役は `speakerOrder` の次の人であり、レベルの重みがない。**レベル5の説明者をレベル1の人が監視する組み合わせが普通に起きる**（実装で確認） | 提示数の上限を15から10へ下げた。監視役へ渡す集合は説明者と同じに保つ |
| 中級者の難化の根拠 | レベル2の3→5語、レベル3の4→8語は、机上レビューが示した「レベル5で1語で即答される」からは導けない | レベル1〜2を据え置き、3/3/5/7/10へ改めた |

**収録数は最大提示数と同じにした。** 最大提示数より多く収録すると、どのレベルにも提示されない語が生まれ、検証3がその語を書くことを強制する。

### 10語の選び直し

末尾を機械的に切って確定させていない。次の基準で選んだ。

1. 既存の禁止語と禁止範囲が重複しない
2. 実際に説明に使いそうな語である
3. 禁止しても、別の説明経路が残る

複合語と単語のどちらを残すかは、**決め手になる語句を残し、汎用語は開けた**。
`Oprah Winfrey` は `talk show` を残して `show` を落とし、`Bruno Mars` は曲名 `Uptown Funk` を残して `funk` を落とした。

初版の記述は「説明経路をより広く塞ぐ側を残した」としていたが、PRレビューの指摘により訂正した。
単語のほうが禁止の範囲は広い（`show` を禁じればあらゆる用法が塞がる）。
残したのは範囲の広い側ではなく、**その語句が出たら正解が割れる決め手の側**である。
汎用語を開けておくと説明の余地が残るという副次的な利点もある。

| 検証 | 件数 | 内容 |

検証13は導入直後に50件を捕まえた。残る84枠は10語への切り落としで消えた。
**不規則変化（`children` と `child`）は文字列比較では判定できない**ため、`Anpanman` と `Elmo` の2件を人手で直した。検査の限界として記録する。

### 下位の語の質

**6位以降の語は上位より弱い。** 観点Bが「下位が死に札の温床になる」と予測したとおりである。
15語のうち11〜15位は最も弱い帯であり、10語へ下げたことでその帯は落ちた。
それでも6〜10位が上位5語と同じ強さだとは言えない。確度: **未検証**。

## 10語のクロスレビュー2巡（2026-09-09）

2026-09-08に禁止語を10語へ増やしたが、そのときのクロスレビューは**5語時代のデータに対して行ったもの**だった。
10語の一覧そのものは作成者の自己判断しか根拠になっていなかったため、改めて3観点を回した。

観点の担当は固定したまま、問いを1巡目と変えた（[README](./README.md) の「レビューの観点を固定する」）。

### 作成者の側の誤りとして記録すること

検証17の根拠を初版で**逆に書いていた**。
「片方を禁止すればもう片方を言う理由がない（＝枠が死ぬ）」と書いたが、これは誤りである。
`hot` を塞げば説明者は `warm` へ逃げるため、両方を塞ぐこと自体には効果がある。

正しい根拠は別で、レベル1〜2には先頭3語しか提示しないため、
3枠のうち2枠が同じ概念だと**そのレベルで塞げる経路が2つに減る**ことである。
枠の死ではなく概念の被覆の狭さの問題であり、差し替えという対処は変わらないが理由が違う。

同種の取り違え（説明経路をより広く塞ぐ側を残した／決め手になる語句を残した）を
2026-09-08にも指摘されており、この成果物で2度目である。

## レビューの限界

* **クロスレビューを経ていない**。この記録は作成者自身の点検であり、独立した検証ではない
* **実プレイのデータがない**。所要時間・得点分布・成立枚数はいずれも未実測である
* **知名度の判断に根拠がない**。「教科書の範囲」は作成者の推定であり、実際の教科書と突き合わせていない。200枚という枚数の都合で知名度の下限を下げており、Famous Figures より想起できないカードの比率が高いと見込むが、これも推定である
* **分野の枚数は手で数えた値である**。データに分類を持たせていないため、機械で再現できない
* **偉人の選定に地域の偏りがある**。欧米が中心で、アフリカ・中東・南米・東南アジアの人物が少ない。意図した偏りではなく、作成者の知識の偏りである
