### 人物セットと分けた理由

このセットの狙いは、**知識に依存しない説明の練習**である。

Famous Figures は「その人物を知っているか」が成否を分ける。
知らないカードを引いた説明者は、英語力と無関係に沈黙する（スキップを1回に限っているのはそのためである。[基本設計/09](../基本設計/09_DONTSAYITゲームモジュール.md)）。

身の回りのものには、この失敗経路がほぼない。
`umbrella` を知らない参加者はいないため、成否は「用途・形・使う場面をどう英語にするか」だけで決まる。
その代わり、説明の型が「用途を言う」に寄りやすい。多様性は人物セットより低いと見込む（確度: **未検証**）。

### 制約カードを人物セットと変えた理由

`no_country`（国名と地名を使わない）と `no_job`（職業と役割の名前を使わない）を載せていない。
どちらも、もののお題では満たすのが自明であり、レベル5への上乗せとして機能しないためである。

代わりに、このセットで説明の中心になる3つの軸を1つずつ塞ぐ制約を置いた。

| 制約 | 塞ぐもの |
| --- | --- |
| `no_shape_color` | 形と色。見た目で言い切る経路 |
| `no_place` | どこにあるか。設置場所で当てさせる経路 |
| `no_material` | 素材。「金属の」「紙の」で絞る経路 |

作成時に次を確認した。**独立した観点による検証ではない**。

* **語の難度**: 正解はいずれも中学英語の範囲か、日本語でも同じ音で通じる語（`smartphone` / `camera`）である。レベル1〜2の回答者が「聞き取れても語が出ない」経路は残る

## 禁止語を10語へ増やした（2026-09-08）

収録数を5語から10語へ増やし、レベル別の提示数を 3/3/5/7/10 とした（[基本設計/09](../基本設計/09_DONTSAYITゲームモジュール.md)のレベル差の吸収）。
**提示数は実プレイで確かめるための暫定値である。**

クロスレビュー観点Bの結論が根拠である。

> 説明が成立しないカードは573枚中0枚。問題は一貫して**逆方向**、すなわち5枠で塞ぎきれず1語で即答されるカードの多さである。

5枠しかないと、有用な禁止語を捨てて別の禁止語を入れる取引が生じていた。
前巡の修正では、共演者名を入れるために既存の禁止語を落とす取引を46回行っている。

### 初版の15語から10語へ下げた

最初は15語で実装したが、PRレビューで3点の指摘を受けて10語へ下げた。

| 指摘 | 内容 | 対処 |
| --- | --- | --- |
| 冗長な枠 | 追加した語句に先行する禁止語がそのまま含まれていた。**573枚中116枚・134枠**（`ruler` の `straight` / `line` に対する `straight line`、`Pikachu` の `cheek` に対する `red cheek`）。読む負担だけ増えて難度は上がらず、実効的な制限数がカードごとに変わる | 検証13を新設し、134枠すべてを差し替えた |
| 監視役の負荷 | 監視役は `speakerOrder` の次の人であり、レベルの重みがない。**レベル5の説明者をレベル1の人が監視する組み合わせが普通に起きる**（実装で確認） | 提示数の上限を15から10へ下げた。監視役へ渡す集合は説明者と同じに保つ |
| 中級者の難化の根拠 | レベル2の3→5語、レベル3の4→8語は、机上レビューが示した「レベル5で1語で即答される」からは導けない | レベル1〜2を据え置き、3/3/5/7/10へ改めた |

**収録数は最大提示数と同じにした。** 最大提示数より多く収録すると、どのレベルにも提示されない語が生まれ、検証3がその語を書くことを強制する。

### 10語の選び直し

末尾を機械的に切って確定させていない。次の基準で選んだ。

1. 既存の禁止語と禁止範囲が重複しない
2. 実際に説明に使いそうな語である
3. 禁止しても、別の説明経路が残る

複合語と単語のどちらを残すかは、**決め手になる語句を残し、汎用語は開けた**。
`Oprah Winfrey` は `talk show` を残して `show` を落とし、`Bruno Mars` は曲名 `Uptown Funk` を残して `funk` を落とした。

初版の記述は「説明経路をより広く塞ぐ側を残した」としていたが、PRレビューの指摘により訂正した。
単語のほうが禁止の範囲は広い（`show` を禁じればあらゆる用法が塞がる）。
残したのは範囲の広い側ではなく、**その語句が出たら正解が割れる決め手の側**である。
汎用語を開けておくと説明の余地が残るという副次的な利点もある。

## 10語のクロスレビュー2巡（2026-09-09）

2026-09-08に禁止語を10語へ増やしたが、そのときのクロスレビューは**5語時代のデータに対して行ったもの**だった。
10語の一覧そのものは作成者の自己判断しか根拠になっていなかったため、改めて3観点を回した。

観点の担当は固定したまま、問いを1巡目と変えた（[README](./README.md) の「レビューの観点を固定する」）。

| 観点 | この巡の問い |
| --- | --- |
| A | レベル別の提示数 3/3/5/7/10 は成立するか。実効難度はどうなっているか |
| B | 10語にしても1語で即答される経路が残っていないか。禁止語は英語として自然か |
| C | 「機微な語は先頭3語へ」の規則が10語への書き換え後も守られているか |

### この巡でいちばん重い結果

3観点が独立に**約250件**を挙げた。機械検証は当時0エラー・0警告だった。

最大のクラスは「同じ概念に2枠を使っている」（4セット合計55枚）で、
これは検証13を新設して潰したはずの欠陥と**同じ性質が別の軸から出たもの**である。
前の巡を「11枠を直した」で終わらせたことが原因であり、
正しい閉じ方は「そのクラスを検査に落とす」だった。

この巡では検証14〜17を追加し、それが挙げた枠をすべて差し替えた
（[基本設計/09](../基本設計/09_DONTSAYITゲームモジュール.md) の検証項目）。

| 検査 | 内容 | 4セット合計 |
| --- | --- | --- |
| 検証14 | 語形変化だけが違う枠（`small` と `smallest`、`Spain` と `Spanish`） | 11枠 |
| 検証15 | 別名を構成する語が禁止語の枠にある（別名 `chemist` と枠 `chemist shop`） | 5枠 |
| 検証16 | 英式の語の混在。綴りの変種（`grey`/`gray`）と別の語になる対（`queue`/`line`） | 23枠 |
| 検証17（警告） | 同じ概念に2枠（`soccer` と `football`） | 66枠 |

機械に落とせなかった指摘は次のとおりで、レビューでしか見つからない。

* 禁止語が英語として自然か（語順が逆の `hair long`、非文の断片 `science too`）
* その語が説明者の口から実際に出るか（`clink` `nearest` `many names`）
* 機微な語の判断

### 作成者の側の誤りとして記録すること

検証17の根拠を初版で**逆に書いていた**。
「片方を禁止すればもう片方を言う理由がない（＝枠が死ぬ）」と書いたが、これは誤りである。
`hot` を塞げば説明者は `warm` へ逃げるため、両方を塞ぐこと自体には効果がある。

正しい根拠は別で、レベル1〜2には先頭3語しか提示しないため、
3枠のうち2枠が同じ概念だと**そのレベルで塞げる経路が2つに減る**ことである。
枠の死ではなく概念の被覆の狭さの問題であり、差し替えという対処は変わらないが理由が違う。

同種の取り違え（説明経路をより広く塞ぐ側を残した／決め手になる語句を残した）を
2026-09-08にも指摘されており、この成果物で2度目である。

機微な語の指摘は25件だったが、語彙リストによる573枚の掃引では143件が候補に挙がった。
大半は色や競走の意味での誤検出（消しゴムの `white`、水泳の `race`、電池の `dead`）だが、
掃引しなければ `Ferdinand Magellan` の `die`@10 と `Captain Cook` の `die there`@9 は残っていた。
