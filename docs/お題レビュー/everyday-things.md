### 人物セットと分けた理由

このセットの狙いは、**知識に依存しない説明の練習**である。

Famous Figures は「その人物を知っているか」が成否を分ける。
知らないカードを引いた説明者は、英語力と無関係に沈黙する（スキップを1回に限っているのはそのためである。[基本設計/09](../基本設計/09_DONTSAYITゲームモジュール.md)）。

身の回りのものには、この失敗経路がほぼない。
`umbrella` を知らない参加者はいないため、成否は「用途・形・使う場面をどう英語にするか」だけで決まる。
その代わり、説明の型が「用途を言う」に寄りやすい。多様性は人物セットより低いと見込む（確度: **未検証**）。

### 制約カードを人物セットと変えた理由

`no_country`（国名と地名を使わない）と `no_job`（職業と役割の名前を使わない）を載せていない。
どちらも、もののお題では満たすのが自明であり、レベル5への上乗せとして機能しないためである。

代わりに、このセットで説明の中心になる3つの軸を1つずつ塞ぐ制約を置いた。

| 制約 | 塞ぐもの |
| --- | --- |
| `no_shape_color` | 形と色。見た目で言い切る経路 |
| `no_place` | どこにあるか。設置場所で当てさせる経路 |
| `no_material` | 素材。「金属の」「紙の」で絞る経路 |

## 自己点検（クロスレビューの代替）

作成時に次を確認した。**独立した観点による検証ではない**。

* **語の難度**: 正解はいずれも中学英語の範囲か、日本語でも同じ音で通じる語（`smartphone` / `camera`）である。レベル1〜2の回答者が「聞き取れても語が出ない」経路は残る
* **禁止語の並び順**: 先頭3語に「用途」「置き場所」「主要な特徴」が来るよう並べた。レベル1〜2はこの3語を失う
* **説明の成立性**: 5語すべてを禁止した状態で、各カードに1本ずつ説明の道筋があることを机上で確認した。確認したのは存在だけで、90秒で言えるかは見ていない

## 禁止語を15語へ増やした（2026-09-08）

収録数を5語から15語へ増やし、レベル別の提示数を 3/5/8/11/15 とした（[基本設計/09](../基本設計/09_DONTSAYITゲームモジュール.md)のレベル差の吸収）。

クロスレビュー観点Bの結論が根拠である。

> 説明が成立しないカードは573枚中0枚。問題は一貫して**逆方向**、すなわち5枠で塞ぎきれず1語で即答されるカードの多さである。

5枠しかないと、有用な禁止語を捨てて別の禁止語を入れる取引が生じていた。
前巡の修正では、共演者名を入れるために既存の禁止語を落とす取引を46回行っている。

### この作業で機械検証が捕まえた誤り

573枚へ10語ずつ足す過程で、検証が**47件**を落とした。

| 検証 | 件数 | 内容 |
| --- | --- | --- |
| 検証2 | 35 | 既存の禁止語と重複する語を書いた |
| 検証10 | 24 | 複合語の構成要素で、規則上すでに禁止されている語を書いた |
| 検証1 | 3 | 正解の構成語を書いた |
| 検証9 | 1 | 3語の禁止語を書いた |
| 検証12 | 1 | 別名と重複する語を書いた |

検証10の24件が最も多い。5語のときは複合語の構成要素を書く余地が少なかったが、10語足すと自然に踏む（`headphones` の `head`、`bookshelf` の `shelf`、`printer` の `print`、`Popeye` の `eye`、`Florence Nightingale` の `night`）。
前巡でこの検査を入れていなければ、規則上すでに禁止されている語で枠を潰したまま気づけなかった。

### 下位の語の質

**6位以降の語は上位より弱い。** 観点Bが「positions 6-15 が死に札の温床になる」と予測したとおりである。

上位5語は「その語を言えば正解が割れる」語だが、下位は「関連はするが説明に使われない語」が混ざる。
実際に説明を塞ぐのは上位8語程度で、レベル4〜5への上乗せは想定より小さい可能性がある。確度: **未検証**。

下位の語の質はカード単位で人手確認していない。実プレイで「その語が実際に出たか」を記録する。

## レビューの限界

* **クロスレビューを経ていない**。この記録は作成者自身の点検であり、独立した検証ではない
* **実プレイのデータがない**。所要時間・得点分布・成立枚数はいずれも未実測である
* **ネイティブ話者による確認を経ていない**。禁止語の自然さ（`after bath` / `two wheels`）は判断していない
* **語彙の難度を測っていない**。「中学英語の範囲」は作成者の判断であり、語彙リストと突き合わせていない
