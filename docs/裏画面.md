# 裏画面（ペアの指定）

## 結論

裏画面は、主催者がペア戦で「この2人を必ず同じペアにする」と指定するための画面である。
通常の画面からはリンクしておらず、URLを直接開いたときだけ表示される。

開かなければ、ペアは従来どおりレベルを揃えて自動で組まれる。
指定した組は参加者の画面に一切出ず、参加者には自動で組まれたように見える。

指定を使うのは MIND MELD と TWO-HEADED SPEAKER の2本である。
SECRET TEAMS など、ほかのゲームでは指定は使われない。

設計判断の正本は [ADR-0035](./adr/0035-ペアの指定は裏画面で行い参加者に伏せる.md) である。
本文書は主催者向けに、開き方と使い方と注意点をまとめる。

## 開き方

部屋コードが `ABCD` の場合、次のURLを開く。

```text
https://<アプリのドメイン>/room/ABCD?mode=backstage
```

参加者として入っている端末とは別のタブか、別の端末で開く。
開いても参加者には数えられず、ロビーの人数も増えない。

URLの `?mode=backstage` を付け忘れると、通常の参加の画面になる。
部屋コードを含まないURL（`/?mode=backstage`）では裏画面にならない。

## 使い方

1. 参加者が全員ロビーに入ったあとで裏画面を開く。参加者の一覧が出る
2. 組ませたい2人を続けてタップする。指定済みの組の一覧に加わる
3. 必要な組をすべて指定する。指定できるのは4組まで（8人で全員分）である
4. 組を外すときは、その組の「外す」を押す。「すべて外す」で指定をなくせる
5. ホストが MIND MELD か TWO-HEADED SPEAKER を選んで始めると、指定した2人が必ず同じペアになる。指定しなかった人は自動で組まれる

画面の上部に、選択中のゲームで指定が使われるかどうかが出る。
指定はゲームの選択前でも、ゲームの最中や結果の表示中でもできる。
変更は次にゲームを始めたときから効く。

2人目をタップする前に同じ人をもう一度タップすると、選択を取り消せる。
既に組に入っている人は選べない。

## 覚えておくこと

### 指定は外すまで残る

指定は、「次のゲームへ」でロビーに戻っても消えない。
同じ顔ぶれで続けて遊ぶ間、毎回同じペアになる。
1回だけのつもりで指定した場合は、終わったら外す。

指定が消えるのは、次の場合だけである。

* 裏画面で外したとき
* 指定に入っている人を、ホストがロビーで外したとき（その人を含む組だけが消える）
* 部屋が破棄されたとき（最終アクセスから2時間）

### 「自動では出ない組」の警告

レベルを揃える自動編成では出ない組を指定すると、組に「自動では出ない組」の印が付き、警告が出る。
たとえばレベル5の2人を組ませる指定は、自動編成では出ない。

ロビーでは全員のレベルが見えている。
自動では出ない組がペアになると、参加者がレベルを見比べて、手で決めたことに気付く可能性がある。

警告が出ても指定はそのまま使われる。
気付かれてもよいかどうかは主催者が判断する。

同じ組が何度も続くことでも、手で決めたと気付かれる可能性がある。

### この画面を参加者に見せない

指定は裏画面にだけ表示される。
画面を覗かれると、指定が知られる。

### 裏画面は同時に2つまで

同じ部屋の裏画面は、同時に2つまで開ける（スマホとPCなど）。
3つ目を開くと、一番古い裏画面の接続が閉じ、「別の端末でこの部屋の裏画面が開かれた」と表示される。
閉じられた端末で使い続けるときは、再読み込みする。

### 参加者もURLを知れば開ける

裏画面には本人確認が無い。
部屋コードは参加者全員に見えているため、URLの形（`?mode=backstage`）を知った参加者は、裏画面を開いて指定を見ることも書き換えることもできる。
リポジトリのソースを読めば、URLの形は分かる。

これは不変条件3「公開値を認証に使わない」の例外として、被害の範囲（ペアの指定が漏れるか書き換わる）を受け入れて決めたものである。
裏画面からできるのはペアの指定だけであり、ゲームの選択、開始、ゲーム内の操作や、他人の秘密情報の閲覧はできない。
指定の漏れや書き換えが場で問題になった場合は、部屋を作った端末に管理用の鍵を持たせる方式へ移る（ADR-0035の「代案」）。

## うまくいかないとき

| 症状 | 原因と対処 |
| --- | --- |
| 参加者の名前とレベルの入力画面が出る | URLに `?mode=backstage` が付いていない。付けて開き直す |
| 「別の端末でこの部屋の裏画面が開かれた」と出る | 3つ目の裏画面が開かれ、この画面の接続が閉じた。再読み込みすると、この端末で開き直せる |
| 「指定を保存できませんでした」と出る | 指定に入れた人が直前に部屋から外された可能性がある。一覧を見て指定し直す |
| 「接続が切れているため送れませんでした」と出る | 再接続を待ってから、もう一度操作する |
| 「ゲームの一覧を取得できませんでした」と出る | 選択中のゲームで指定が使われるかを表示できない。指定そのものは保存され、使うゲームでは使われる |
| 指定したのに別のペアになった | 選んだゲームが MIND MELD と TWO-HEADED SPEAKER 以外である。画面上部の表示で、指定が使われるゲームかを確かめる |
