# ビジュアルデザイン指針: BEB Party（仮称）

## 結論

方向性は「**お祭り格闘ゲームの緊張感 × ポップレースゲームの丸さとスピード感**」とする。

具体的には、深紺の地に赤・青・黄の原色をぶつけ、斜め構図とハードシャドウで激突感を出し、UI部品は大きな角丸と太い輪郭で丸く保つ。

書体は見出しにDela Gothic One、本文にM PLUS Rounded 1cを使う。
どちらもSIL OFLの無料フォントで、使用グリフのサブセット化により自前配信する（ゼロコスト原則を維持）。

任天堂作品のロゴ・キャラクター・素材は一切使わず、「同じ気持ちよさの文法」だけを借りる。

## デザインコンセプト

このゲームの体験は「和やかな英会話」ではなく「尋問と疑心暗鬼のお祭り」である。

そこで画面の性格をフェーズごとに切り替える。

| フェーズ | 参照する気持ちよさ | 画面の性格 |
| --- | --- | --- |
| ホーム・ロビー | レースゲームのメニュー | 明るい空色、丸いボタン、キャラクターセレクト風の参加者グリッド |
| 配役発表 | 格闘ゲームの「参戦」演出 | 全画面スプラッシュ、斜めのカットイン、一拍おいて役柄をドン |
| 捜査 | 格闘ゲームの試合中HUD | 深紺の地、上部に太いタイマー、証言カードは白地で可読性最優先 |
| 投票 | 対戦カードのVS画面 | 赤と青の斜め分割、容疑者グリッドから1人を選ぶ |
| 開示 | リザルト発表 | スピードライン背景、犯人名のズームイン、勝敗の大文字 |

## デザイントークン

### カラー

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--ground` | `#0D142E` | 基調の深紺。捜査・投票・開示の地 |
| `--sky` | `#4EC9FF` | ロビー系の明るい地。空色グラデーションの起点 |
| `--panel` | `#F7F8FD` | カード・パネルの地。証言カードはこの上に黒文字 |
| `--red` | `#FF3D3D` | 犯人・危険・投票アクション。VS画面の片翼 |
| `--blue` | `#2E7CF6` | 市民・情報・通常アクション。VS画面のもう片翼 |
| `--yellow` | `#FFC400` | タイマー・強調・スコア。深紺の上で最も目立つ色 |
| `--ink` | `#161B33` | パネル上の文字色。紺寄りの黒（純黒は使わない） |

赤と青は色覚多様性に配慮し、常にアイコンまたはラベルを併記して色だけで意味を伝えない。

### タイポグラフィ

| 役割 | 書体 | 使い方 |
| --- | --- | --- |
| 見出し・演出文字 | Dela Gothic One | フェーズタイトル、スプラッシュ、ボタンラベル。`skew(-6deg)` で勢いを付ける |
| 本文・UI | M PLUS Rounded 1c (400/700) | 証言カード、説明文、リスト。証言英文は18px以上 |
| 数字（タイマー・スコア） | M PLUS Rounded 1c 700 + `tabular-nums` | 桁揃えを保証する |

フォントはビルド時に使用グリフへサブセット化してWorkerから配信する。
Google FontsのCDN参照はしない（外部依存を減らし、読み込みを速くするため）。

日本語グリフの使用範囲はUI固定文言だけでは決まらない。
`hintJa` / `briefing.ja` 等の事件データ由来の日本語を含めるため、サブセット化の入力は `client/` の文言と `cases/*.json` の日本語フィールドの両方から抽出する。
抽出手順は [基本設計/04_事件データと検証.md](./基本設計/04_事件データと検証.md) を正とし、CIのビルド工程に組み込む。

### ライセンス表記

Dela Gothic One と M PLUS Rounded 1c はいずれもSIL Open Font License 1.1である。
サブセット化は改変にあたるため、次の2点を守る。

* OFLのライセンス全文を `client/` のフォント資産と同じディレクトリに同梱し、配信物に含める
* アプリ内にライセンス表記画面（またはフッターのリンク）を設け、書体名と著作権表示を記載する

Reserved Font Nameの指定がある場合、サブセット後のフォントファイル名に元の書体名を使えない。
使用するバージョンのOFLヘッダを確認し、指定があれば内部名を変更する。

### 形状・エフェクト

| トークン | 値 | 意図 |
| --- | --- | --- |
| 斜め角度 | `-8deg` 固定 | 全画面で同じ角度に統一し、雑多に見えるのを防ぐ |
| 角丸（ボタン） | `999px` | レースゲーム的な丸ボタン |
| 角丸（カード） | `20px` | 丸いが締まる値 |
| ハードシャドウ | `0 6px 0 rgba(0,0,0,.25)` | ぼかさない影で玩具的な立体感を出す |
| 輪郭 | `3px` 実線 | 細線を使わない。太い輪郭が基本 |

### モーション

* 時間は150〜250ms、イージングは `cubic-bezier(.2, 1.4, .4, 1)`（少し行き過ぎて戻る）
* フェーズ遷移は斜めワイプ（-8degに合わせる）
* 演出の山場は配役発表と開示の2箇所に限定し、捜査中は動かさない（会話の邪魔をしない）
* `prefers-reduced-motion` ではワイプ・ズームを即時切替に落とす

## 画面別の要点

* **ロビー**: 参加者は正方形タイルのグリッドで表示し、レベルを1〜5の星バッジで示す。格闘ゲームのキャラクターセレクトの文法をそのまま使う
* **配役発表**: 各自のスマホに全画面カットインで役柄を表示する。犯人には赤地、市民には青地。1秒の溜めの後に表示し、画面を伏せる時間を作る
* **捜査**: 演出を最小にし、証言カードの可読性を最優先する。白パネル・18px以上・日本語ヒント併記。タイマーは上部固定の黄色バー。日本語ヒントは英文より小さく低コントラストにし、視線が英文へ先に行く階層にする（英文を読まずヒントだけで済ませる動機を作らない）
* **投票**: 赤青の斜め分割地に容疑者タイルを並べる。選択中のタイルは黄色の太枠で示す
* **開示**: スピードラインの放射背景に犯人名をズームイン。その後に嘘カードと矛盾の解説を落ち着いたパネルで表示する

## テーマ対応

ゲーム画面は世界観優先で単一テーマ（フェーズごとの固定配色）とし、OSのライト/ダーク設定に追従しない。

すべての画面で背景色を明示的に塗り、ホスト環境の地色に依存しない。

## 実装方針

* 色・形状・モーションはCSSカスタムプロパティとして `client/` に一元定義する
* 斜め構図は `clip-path` とCSSグラデーションで実装し、画像アセットを持たない（バンドル軽量化とゼロコスト維持）
* スピードライン等の装飾は `repeating-conic-gradient` / `repeating-linear-gradient` で描く

## 権利面の注意

参照作品の名称・ロゴ・キャラクター・スクリーンショット・効果音をアプリ内およびストア文言に使用しない。
借りるのは構図・色数・テンポといった文法に限る。
