# ビジュアルデザイン指針: BEB Party（仮称）

## 結論

方向性は「**お祭り格闘ゲームの緊張感 × ポップレースゲームの丸さとスピード感**」とする。

具体的には、深紺の地に赤・青・黄の原色をぶつけ、斜め構図とハードシャドウで激突感を出し、UI部品は大きな角丸と太い輪郭で丸く保つ。

書体は見出しにDela Gothic One、本文にM PLUS Rounded 1cを使う。
どちらもSIL OFLの無料フォントで、使用グリフのサブセット化により自前配信する（ゼロコスト原則を維持）。

任天堂作品のロゴ・キャラクター・素材は一切使わず、「同じ気持ちよさの文法」だけを借りる。


## ゲーム選択カード

ロビーのゲーム選択は、格闘ゲームのキャラクターセレクトの文法で作る。

* 1行1ゲームの縦積みとし、左から「アイコン（絵文字）」「タイトル（ディスプレイ書体・斜体）」「一行説明」「人数バッジ」の順に読ませる
* アイコンはゲームモジュールが `icon` として持つ絵文字1〜2字とする。画像アセットを増やさないため、書体で描ける文字に限る
* 一行説明（`tagline`）は、何をする遊びかが分かる長さにする。選択前に中身が想像できることを優先し、あおり文句にしない
* 選択中はカードを持ち上げ（`translateY`）、黄色の太い縁・斜めのスピードライン・角の `✓` で示す。アイコンの下地は赤へ変える
* 主要ボタン（ゲームスタート）だけを画面下端へ寄せる。選択UIごと下げると、収録ゲームが少ないときに画面の底へ取り残される

文言の実体はサーバの `GameModule` にあり、`/api/catalog` でクライアントへ配る（[基本設計/01](./基本設計/01_サーバ.md)）。
フォントサブセットの入力にも含める（[基本設計/04](./基本設計/04_事件データと検証.md)）。

## デザインコンセプト

この体験は「和やかな英会話」ではなく「尋問と疑心暗鬼のお祭り」である。

デザイントークン（色・書体・形状・モーション）はゲーム集全体で共通とし、収録ゲームが増えても同じ器に見えるようにする。
そのうえで画面の性格をステージごとに切り替える。

共通コアの画面（全ゲームで共通）。

| 画面 | 参照する気持ちよさ | 画面の性格 |
| --- | --- | --- |
| ホーム・ロビー | レースゲームのメニュー | 明るい空色、丸いボタン、キャラクターセレクト風の参加者グリッド。ゲーム選択はタイトルカードを並べる |
| ホスト画面 | 大会モニタ | ステージ名とタイマーだけを大写し |

DETECTIVESのステージ（`client/games/detectives/`）。

| ステージ | 参照する気持ちよさ | 画面の性格 |
| --- | --- | --- |
| 配役発表 | 格闘ゲームの「参戦」演出 | 全画面スプラッシュ、斜めのカットイン、タップと一拍をおいて役柄をドン |
| 捜査 | 格闘ゲームの試合中HUD | 深紺の地、上部に太いタイマー、証言カードは白地で可読性最優先 |
| 投票 | 対戦カードのVS画面 | 赤と青の斜め分割、容疑者グリッドから1人を選ぶ |
| 開示 | リザルト発表 | スピードライン背景、犯人名のズームイン、勝敗の大文字 |

ゲームを追加するときは、共通のデザイントークンを使ったうえでステージごとの性格を新たに定義する。
トークン自体を増やす場合は本文書を更新する。

## デザイントークン

### カラー

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--ground` | `#0D142E` | 基調の深紺。捜査・投票・開示の地 |
| `--sky` | `#4EC9FF` | ロビー系の明るい地。空色グラデーションの起点 |
| `--panel` | `#F7F8FD` | カード・パネルの地。証言カードはこの上に黒文字 |
| `--red` | `#FF3D3D` | 犯人・危険・投票アクション。VS画面の片翼 |
| `--blue` | `#2E7CF6` | 市民・情報・通常アクション。VS画面のもう片翼 |
| `--yellow` | `#FFC400` | タイマー・強調・スコア。深紺の上で最も目立つ色 |
| `--ink` | `#161B33` | パネル上の文字色。紺寄りの黒（純黒は使わない） |

濃淡の対（`--ground-2` `#131C42` / `--sky-deep` `#1E8FE0` / `--red-deep` `#D42121` / `--blue-deep` `#1B5CD6`）は、グラデーションとボタンの下端の影に使う。
基調色と併記して面に厚みを出すためのものであり、単独で新しい意味を持たせない。

パネル上の弱い文字には `--ink-soft` `#4A5170`、深紺の地の上の弱い文字には `--mist` `#B9C2E8` を使う。
地色ごとに別トークンを持つのは、同じ灰色を両方の地に載せるとどちらかで読めなくなるためである。

赤と青は色覚多様性に配慮し、常にアイコンまたはラベルを併記して色だけで意味を伝えない。

### タイポグラフィ

| 役割 | 書体 | 使い方 |
| --- | --- | --- |
| 大きな見出し・演出文字 | Dela Gothic One | ステージタイトル、役柄カード、部屋コード、タイマー。`skew(-6deg)` で勢いを付ける |
| 小見出し・ボタン・バッジ | M PLUS Rounded 1c 700 | 1.5rem以下の日本語すべて |
| 本文・UI | M PLUS Rounded 1c (400/700) | 証言カード、説明文、リスト。証言英文は18px以上 |
| 数字（タイマー・スコア） | M PLUS Rounded 1c 700 + `tabular-nums` | 桁揃えを保証する |

Dela Gothic One を大きな文字に限るのは、この書体が超極太で、1rem前後の漢字が塊になって読めなくなるためである（実機相当のスクリーンショットで確認）。
グリフ自体は正常であり、28px以上なら問題なく読める。

トークンは用途で分ける。`--font-display` がDela Gothic One、`--font-heading` がM PLUS Rounded 1cの太字（`--font-heading-weight`）、`--font-body` が本文である。
ラテン文字だけのラベル（`HOST` バッジ等）は小さくても `--font-display` を使ってよい。

フォントはビルド時に使用グリフへサブセット化してWorkerから配信する。
Google FontsのCDN参照はしない（外部依存を減らし、読み込みを速くするため）。

日本語グリフの使用範囲はUI固定文言だけでは決まらない。
`hintJa` / `briefing.ja` 等の事件データ由来の日本語を含めるため、サブセット化の入力は `client/` の文言と `content/detectives/*.json` の日本語フィールドの両方から抽出する。
抽出手順は [基本設計/04_事件データと検証.md](./基本設計/04_事件データと検証.md) を正とし、CIのビルド工程に組み込む。

### ライセンス表記

Dela Gothic One と M PLUS Rounded 1c はいずれもSIL Open Font License 1.1である。
サブセット化は改変にあたるため、次の2点を守る。

* OFLのライセンス全文を `client/` のフォント資産と同じディレクトリに同梱し、配信物に含める
* アプリ内にライセンス表記画面（またはフッターのリンク）を設け、書体名と著作権表示を記載する

フッターは全画面共通で画面下端に固定する（遊び方とライセンス表記の2つ）。
各画面はコンテンツ下端に `--footer-clearance` の余白を取り、主要ボタンとフッターが近接しないようにする。
背景色が画面ごとに違うため、フッターのリンクは自前の下地を持たせて可読性を保つ。

Reserved Font Nameの指定がある場合、サブセット後のフォントファイル名に元の書体名を使えない。
使用するバージョンのOFLヘッダを確認し、指定があれば内部名を変更する。

### 形状・エフェクト

| トークン | 値 | 意図 |
| --- | --- | --- |
| 斜め角度 | `-8deg` 固定 | 全画面で同じ角度に統一し、雑多に見えるのを防ぐ |
| 角丸（ボタン） | `999px` | レースゲーム的な丸ボタン |
| 角丸（カード） | `20px` | 丸いが締まる値 |
| 角丸（タイル） | `14px` | 参加者タイル。カードより角を立てて枚数の多さを整える |
| ハードシャドウ | `0 6px 0 rgba(0,0,0,.25)` | ぼかさない影で玩具的な立体感を出す |
| タイルの影 | `0 4px 0 rgba(0,0,0,.28)` | タイルは面積が小さいため影も浅くする |
| 輪郭 | `3px` 実線 | 細線を使わない。太い輪郭が基本 |

### モーション

* 時間は150〜250ms、イージングは `cubic-bezier(.2, 1.4, .4, 1)`（少し行き過ぎて戻る）
* ステージ遷移は斜めワイプ（-8degに合わせる）
* 演出の山場は配役発表と開示の2箇所に限定し、捜査中は動かさない（会話の邪魔をしない）
* `prefers-reduced-motion` ではワイプ・ズームを即時切替に落とす

## 画面別の要点

* **ロビー**: 参加者は正方形タイルのグリッドで表示し、レベルを1〜5の星バッジで示す。格闘ゲームのキャラクターセレクトの文法をそのまま使う
* **配役発表**: 各自のスマホに全画面カットインで役柄を表示する。犯人には赤地、市民には青地。表示の前に中立色の伏せ面を挟み、本人のタップを待ってから600msの溜めを経て開く（手順と文言は [基本設計/02](./基本設計/02_クライアント.md) を正とする）
* **捜査**: 演出を最小にし、証言カードの可読性を最優先する。白パネル・18px以上・日本語ヒント併記。タイマーは上部固定の黄色バー。日本語ヒントは英文より小さく低コントラストにし、視線が英文へ先に行く階層にする（英文を読まずヒントだけで済ませる動機を作らない）
* **投票**: 赤青の斜め分割地に容疑者タイルを並べる。選択中のタイルは黄色の太枠で示す
* **開示**: スピードラインの放射背景に犯人名をズームイン。その後に嘘カードと矛盾の解説を落ち着いたパネルで表示する

上の5項目のうちロビーは共通コアの画面であり、残る4項目はDETECTIVESの画面である。

DON'T SAY ITは4画面を持つ（[基本設計/09](./基本設計/09_DONTSAYITゲームモジュール.md)）。

* **ブリーフィング**: 3役と得点を1画面で示す。説明者・監視役・回答者を赤・黄・青の帯で並べ、以降の画面でも同じ色を役の識別に使う
* **交代**: 次の説明者を、ロビーと同じ正方形タイルで持ち上げて示す。説明者の端末にだけ開始ボタンを出し、他の端末には順番待ちの一覧を出す。30秒の締切は数字で見せない（急かすとカードを読み終える前に開始を押す）
* **説明**: 3役で画面の中身が別物になる。共通なのは上部固定の黄色いタイマーバーと、そのラウンドで成立した枚数だけとする
* **結果**: 得点表を1位から縦に並べ、1位のタイルだけディスプレイ書体で拡大する。その下に使い終えたカードを人物名と禁止語の対で並べ、最後に重要表現を置く

説明ステージの3役は次のように描き分ける。

| 役 | 画面 |
| --- | --- |
| 説明者 | 人物名をディスプレイ書体で最大に置き、その下に禁止語を赤地のリストで並べる。制約カードがある場合は黄色の帯を人物名の上に出す |
| 監視役 | 禁止語だけを赤地で大きく並べ、人物名の位置には中立色の伏せ面を置く。違反ボタンを下端に固定する |
| 回答者 | 得点・残り時間・成立枚数だけを置き、他の要素を持たせない |

回答者の画面から情報を削るのは、手元を見る理由をなくして顔を上げさせるためである。
説明を聞くゲームで画面に読むものがあると、視線が下がって発話が止まる。
捜査画面で日本語ヒントの階層を下げる判断と同じ理由による。

正解の申告は2段階にする。
説明者が正解ボタンを押すと回答者の一覧がボトムシートで開き、そこで誰が当てたかを選ぶ。
1タップで確定すると、誤タップがそのまま別人への加点になる。

## テーマ対応

ゲーム画面は世界観優先で単一テーマ（フェーズごとの固定配色）とし、OSのライト/ダーク設定に追従しない。

すべての画面で背景色を明示的に塗り、ホスト環境の地色に依存しない。

## 実装方針

* 色・形状・モーションはCSSカスタムプロパティとして `client/core/` に一元定義する。ゲームモジュールはトークンを参照するだけで、独自の色値をハードコードしない
* 斜め構図は `clip-path` とCSSグラデーションで実装し、画像アセットを持たない（バンドル軽量化とゼロコスト維持）
* スピードライン等の装飾は `repeating-conic-gradient` / `repeating-linear-gradient` で描く

### 共通プリミティブ

画面をまたいで同じ形にするため、`client/core/src/tokens.css` に次のクラスを置く。
Svelteのスコープ付きスタイルでは共有できないため、トークンと同じファイルにグローバルクラスとして定義する。

| クラス | 用途 |
| --- | --- |
| `.beb-btn`（`.red` / `.blue` / `.yellow` / `.ghost`） | 丸ボタン。面を `skew(-8deg)` で倒し、内側の `span` を逆に倒して文字は水平に保つ |
| `.beb-tile`（`.empty`） | キャラクターセレクト風のタイル。`.face` の丸アイコンと `.lv` バッジを内包する |
| `.beb-card` | 白パネルのカード。証言カードと開示の解説に使う |
| `.beb-pill`（`.lock`） | カード上のラベル。`.lock` は「聞かれたら答える」等の制約表示 |
| `.beb-speedlines-light` / `.beb-stripes-dark` | 斜めのスピードラインと縞。明るい地と暗い地で使い分ける |

参加者タイルのアイコン色は `playerId` から決める（`client/core/src/face-color.ts`）。
サーバは色を配らない。表示のためだけの派生値である。

## 権利面の注意

参照作品の名称・ロゴ・キャラクター・スクリーンショット・効果音をアプリ内およびストア文言に使用しない。
借りるのは構図・色数・テンポといった文法に限る。
