# 0007: 犯人バリアントは実配役プレイヤーのレベルで抽選する

* ステータス: accepted
* 日付: 2026-08-10

## 決定

犯人バリアントの抽選条件を、キャラクターの `recommendedLevel` ではなく**そのキャラクターに実際に配役されたプレイヤーの自己申告レベル**が3以上であることとする。

条件を満たすバリアントが1つもない場合は、レベルが最も高いプレイヤーのキャラクターのバリアントを選ぶ。

あわせて、証言の表示英文（嘘カードを含む）はレベル1〜5の全レベルを必須とする。

## 理由

当初案はバリアントの `culprit` をリントで「`recommendedLevel` 3以上のキャラクター」に制限していたが、これでは目的を達成しない。

配役は参加者をレベル降順、キャラクターを `recommendedLevel` 降順で対応させる相対的な割り当てであり、絶対的なレベル一致を保証しない。
参加者全員がレベル1〜2の組（想定される主要ユースケース）では、`recommendedLevel: 5` のキャラクターにレベル1のプレイヤーが入る。
このときキャラクター基準のリントは通るが、実際に嘘をつくのはレベル1のプレイヤーであり、「犯人役が初級者に当たると嘘がつけず即バレする」というリスクがそのまま発現する。

同じ理由で、表示英文を「担当キャラクターの推奨レベル帯のみ」とする当初案も成立しない。
配役でレベルがずれることは例外ではなく通常であり、ずれた先の英文が存在しないと表示不能になる。この欠落は機械検証が素通りしていた。

全レベル分の英文が必須になることで事件制作の負荷は上がるが、生成は開発時のAI利用で行い機械検証で欠落を検出するため、運用上の負荷は検証項目の追加で吸収できる。

## 影響

* バリアント抽選はDOのランタイム処理（配役確定後）で行う。事件データ側の静的リントでは決められない
* 事件データは「どのキャラクターが犯人になっても成立する」ことを求められる。バリアント数は原則キャラクター数と同数を目標とする
* 検証項目「表示完全性」は全factの `text` にレベル1〜5すべてを要求する（推奨レベル帯のみでは不可）
* 全員がレベル1〜2の組では、レベル3以上の条件を満たすプレイヤーが存在しない。この場合はフォールバック（最高レベルのプレイヤー）が働くため、嘘の難度はUI側の制約表示で緩和する
