# 0004: 事件データの静的JSON化とCI検証

* ステータス: accepted
* 日付: 2026-08-10

## 決定

事件データは `cases/*.json` の静的ファイルとし、サーバへビルド時にバンドルする。
すべての事件は前方推論による6項目の機械検証をCI必須チェックとする。

## 理由

推理が破綻した事件（解けない・1人で解けてしまう・冤罪が成立する）はこのゲーム最大の死因であり、人手レビューだけでは見落とす。
事件の推理構造は有限の事実と導出規則で閉じているため、決定論的に全数検証できる。

検証エンジンを汎用推論器として作ることで、将来のESCAPEモードの可解性検証（元構想の再検算）と共用できる。

## 影響

* 事件の追加・修正PRは `validate:cases` PASSが必須。検証を回避するマージはしない
* スキーマ変更は `shared/case.ts` と [04_事件データと検証.md](../基本設計/04_事件データと検証.md) を同時更新する
* 機械検証が保証しない品質（英文の自然さ、題材の適切さ）は人手レビューのチェックリストで担保する
