# 0005: MVPはENGLISH DETECTIVES

* ステータス: accepted
* 日付: 2026-08-10

## 決定

最初にリリースするゲームモードをENGLISH DETECTIVES（英語人狼＋推理）1本とする。

## 理由

候補（ESCAPE、DON'T SAY IT、LOST IN TRANSLATION、BROKEN STORY）の中で、会話量・レベル差耐性・ゼロコスト適合を最も高い水準で満たすため。
比較の詳細は [構想v2](../構想v2.md) を正とする。

当初案はDON'T SAY ITだったが、ユーザー判断（2026-08-10）でDETECTIVESに変更した。

## 影響

* 部屋・配役・秘密配布・フェーズ進行の基盤はゲーム横断で再利用できる形で作る（2本目以降の追加コストを下げる）
* 開発順序は「検証エンジン → 事件1本 → UI」とし、事件データの成立性をUIより先に確認する（[設計.md](../設計.md) のロードマップ）
