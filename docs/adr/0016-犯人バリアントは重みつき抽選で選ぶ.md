# 0016: 犯人バリアントは重みつき抽選で選ぶ

* ステータス: accepted
* 日付: 2026-08-18

## 決定

犯人バリアントは、配役されたキャラクター全員を候補とし、**配役されたプレイヤーの自己申告レベルが3以上のキャラクターを3倍の重みで**引く。

レベルによる候補の絞り込みは行わない。どのキャラクターも確率0にならない。

判定にキャラクターの `recommendedLevel` ではなく実プレイヤーのレベルを使う点、および証言の表示英文（嘘カードを含む）をレベル1〜5すべて必須とする点は [ADR-0007](./0007-犯人バリアントは実配役プレイヤーのレベルで抽選する.md) から引き継ぐ。

## 理由

ADR-0007は候補を「実プレイヤーのレベルが3以上」に絞り込む方式だった。
この方式は、候補が1件に縮退したときに犯人を確定させる。

`Player.level` は公開状態に含まれ、`state` で全員に配られる（[ADR-0006](./0006-公開IDと再接続シークレットの分離.md) が秘密にするのは `reconnectToken` だけである）。
参加者はロビーで互いのレベルを見られる。これは「相手のレベルに合わせた英語で話す」ために意図して公開している情報である。

したがって「レベル3以上が1人だけの卓」では、その1人が犯人であることがブリーフィング前に全員へ割れる。
これは想定される主要な卓の1つ（上級者1人 + 初級者5人）でそのまま起きる。実測でも当該分布では100%固定であった。

候補の下限を2件や3件に広げる案も検討したが、絞り込みを残す限り「候補から外れた人は無実」という情報が必ず漏れる。
レベルを公開状態から外す案は、レベル表示が会話の調整に使われている以上採らない。

重みつき抽選は、ADR-0007の目的（嘘をつく負荷の高い役を、英語に余裕のある参加者へ寄せる）を確率として保ちながら、確定を作らない。
上級者1人 + 初級者5人の卓では上級者が犯人になる確率が3/8であり、絞り込み方式の1に対して十分に低い。

## 影響

* 抽選はDOのランタイム処理（配役確定後）で行う。事件データ側の静的リントでは決められない（ADR-0007から変更なし）
* レベル1〜2のプレイヤーが犯人になる回が、混成の卓でも起こりうる。嘘の難度はUI側の制約表示で緩和する
* 「レベル3以上のプレイヤーが居る場合、犯人は必ずその中から選ばれる」ことを前提にしたテスト・文書は成立しない。期待値は「レベル3以上が犯人になりやすい」に変わる
* 事件データは引き続き「どのキャラクターが犯人になっても成立する」ことを求められる
