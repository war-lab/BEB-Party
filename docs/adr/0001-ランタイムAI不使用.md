# 0001: ランタイムAI不使用（ゼロコスト原則）

* ステータス: accepted
* 日付: 2026-08-10

## 決定

本番のアプリからLLM API・音声認識・音声合成を呼ばない。
AIは開発時のコンテンツ生成（事件データ等）にのみ使う。

## 理由

運用費¥0がプロダクトの絶対条件である。
ゲームデザイン側で「勝敗は投票という構造で決まる」「会話は同室の生声」を選んだことで、ランタイムに英語を理解する主体が不要になった（[構想v2](../構想v2.md)）。

代替案として無料枠のあるLLM APIも検討したが、無料枠は恒久保証がなく、利用規約変更で突然コスト化するリスクを排除した。

## 影響

* 英文の自動採点・自動フィードバック機能は実装しない。振り返りは事件データに事前収録した素材で行う
* 「AIで採点したら便利」系の機能提案は、本ADRの変更（新ADR）なしに実装しない
