# プレイヤーアイコンの素材

アイコンの絵の正本は `player-icons-map.mjs` の16×16ドットマップである。
IDと一覧の正本は `shared/core/src/player-icon.ts` の `PLAYER_ICONS`（[ADR-0022](../../../docs/adr/0022-プレイヤーアイコンはIDで持ち絵文字は表示層に置く.md)）。

## 内訳

| パス | 内容 |
| --- | --- |
| `player-icons-map.mjs` | 30件のドットマップと配色。**ここが絵の正本** |
| `svg/<id>.svg` | 生成物。1マス1矩形のベクタ。大きく出す用途に使う |
| `../../public/player-icons/<id>.png` | 生成物。16×16を4倍した64×64のPNG。アプリが読むのはこちら |

## 作り直し方

```bash
pnpm --filter @beb/client-app run icons:generate
```

PNGとSVGの両方を書き出す。
生成物はコミットし、CIで再生成との差分を検査する（基本設計/07）。
一覧から消したIDのファイルが残らないよう、生成時に出力先を作り直す。

PNGの書き出しには `scripts/png.mjs`（RGBA8の最小実装）を使う。
画像ライブラリを依存に加えないためである。

## 描き方の決まり

40px前後で見分けがつくよう、次を守る。

* 目は2×2の塊にする。1マス幅の線は閉じた目に見え、表情の差が出ない
* 口は2マス幅までに留める。4マス幅にすると全員が大口を開けた顔になる
* 耳と角は塗りつぶす。輪郭だけだと角のように見える
* 人物12件は同じ顔の下地を共有し、髪型と小物だけを変える。並べたときに背の高さを揃えるためである

配色は `PALETTE`（輪郭・肌・ほお・白）を共通で使い、アイコン固有の色は各 `colors` に置く。
未定義の記号があれば生成が失敗する。

## 権利

30件すべて本リポジトリで描いたドットマップから生成しており、参照作品のキャラクターを含めない（`docs/ビジュアルデザイン.md` の権利面の注意）。

以前は生成AIで作ったラスタ画像を切り出して使っていたが、次の2点により全件を自作のドットマップへ作り直した。

* 生成物に既存作品のキャラクターと同一の造形が1件混入していた
* ドット絵風でありながらドットの格子を持たず（色数約20万、エッジ間隔3〜15px）、拡大に耐えなかった
