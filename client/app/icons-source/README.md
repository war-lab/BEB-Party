# プレイヤーアイコンの素材

アイコンの絵の正本は `player-icons-art.mjs` の描画コードである。
IDと一覧の正本は `shared/core/src/player-icon.ts` の `PLAYER_ICONS`（[ADR-0022](../../../docs/adr/0022-プレイヤーアイコンはIDで持ち絵文字は表示層に置く.md)）。

## 内訳

| パス | 内容 |
| --- | --- |
| `player-icons-art.mjs` | 30件の描画コードと配色。**ここが絵の正本** |
| `draw.mjs` | 描画に使う最小のラスタ実装（円・楕円・角丸・多角形・線・輪郭付け） |
| `../scripts/generate-player-icons.mjs` | 書き出し |
| `../scripts/png.mjs` | PNGの符号化（RGBA8の最小実装） |
| `../../public/player-icons/<id>.png` | 生成物。128×128。アプリが読むのはこちら |

## 作り直し方

```bash
pnpm --filter @beb/client-app run icons:generate
```

生成物はコミットし、CIで再生成との差分を検査する（基本設計/07）。
一覧から消したIDのファイルが残らないよう、生成時に出力先を作り直す。

倍率を渡すと大きく書き出せる（投影用など）。出力先は `icons-source/out-<辺>/` になり、コミットはしない。

```bash
node scripts/generate-player-icons.mjs 4   # 512x512
```

同じ描画コードから任意の解像度が出るため、素材を作り直さずに大きくできる。

## 描き方の決まり

128×128をマスごとに置くのは現実的でないため、図形の重ね合わせで描く。
40px前後まで縮小しても見分けがつくよう、次を守る。

* 輪郭は最後に `outline()` で一括して付ける（幅4）。輪郭線を自分で描かない
* 面は単色。陰影は下端の1段（`shadeBottom`）と、必要なら明るい面を1つだけにする
* 目は塊で描き、白いハイライトを左上に1つ置く
* 人物12件は同じ頭の下地（`head`）を共有し、髪型と小物だけを変える。並べたときに背の高さを揃えるためである
* 目の中心はy=76、口はy=96前後。髪の裾はy=58までとし、目に被せない

アンチエイリアスはかけない。色数を抑えるとPNGが小さくなり、縮小時のにじみも減る。

## 権利

30件すべて本リポジトリの描画コードから生成しており、参照作品のキャラクターを含めない（`docs/ビジュアルデザイン.md` の権利面の注意）。

以前は生成AIのラスタ画像を切り出して使っていたが、次の2点により全件を自作へ作り直した。

* 生成物に既存作品のキャラクターと同一の造形が1件混入していた
* ドット絵風でありながらドットの格子を持たず（色数約20万、エッジ間隔3〜15px）、拡大に耐えなかった
