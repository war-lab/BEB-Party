# プレイヤーアイコンの素材

`client/public/player-icons/<id>.png`（64×64、30件）の元素材を置く。
アイコンの一覧とIDの正本は `shared/core/src/player-icon.ts` の `PLAYER_ICONS` である（[ADR-0022](../../../docs/adr/0022-プレイヤーアイコンはIDで持ち絵文字は表示層に置く.md)）。

## 内訳

| ファイル | 内容 |
| --- | --- |
| `player-icons-sheet.png` | 29件分の元シート。6列5行に並んだドット絵風イラストで、背景は緑（1535×1024） |
| `blob.svg` | `blob`（23番）のみ自作。16×16のドット絵をSVGの矩形で表現したもの |

## 配布物の作り方

`player-icons-sheet.png` から次の手順で切り出した。CIでの再生成と差分検査は行わない（フォントサブセットと違い、文言の変更で内容が変わらないため）。

1. 緑背景（およそ `#15E419`）を透明にする。緑の判定は色相で行い、`frog` と `alien` の緑を抜かないよう背景側の色域に限る
2. 境界に残る緑かぶりを抑える（緑が他2チャンネルより大きく突出した画素の緑成分を下げる）
3. 連結成分でアイコンを切り出す。番号のラベルは面積で区別して落とす（アイコンは13000画素以上、番号は350画素以下）
4. 正方形のキャンバスに中央寄せし、Lanczosで64×64へ縮小する

`blob.svg` は16×16の格子をそのまま整数倍で64×64へ描き出した。

## 素材の性質

元シートはドット絵風のイラストであり、ドットの格子を持たない（エッジ間隔が3〜15画素で不揃い、色数は約20万色）。
このため最近傍補間での拡大・縮小に耐えない。表示は64px以下に留め、縮小は平滑化を伴う方法で行う。

## 権利

元シートは本プロジェクトで生成した素材であり、参照作品のキャラクターを含めない（`docs/ビジュアルデザイン.md` の権利面の注意）。
23番だけを自作の `blob.svg` に差し替えているのは、生成物に既存作品のキャラクターと同一の造形が含まれていたためである。
